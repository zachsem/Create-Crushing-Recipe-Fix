# Contributing

Thanks for helping improve Create Crushing Recipe Fix.

## Before opening an issue

Please confirm the problem is reproducible with:

- Minecraft 1.18.2
- Forge 40.2.4 or newer in the 1.18.2 branch
- Create 0.5.1i
- The latest release of Create Crushing Recipe Fix

If another mod or datapack changes Create recipes, mention it in the report.

## Bug reports

Use the **Bug report** issue template and include:

- Exact Minecraft, Forge, Create, and patch versions
- Clear reproduction steps
- `latest.log`
- A crash report when applicable
- Any other mods or datapacks that may affect recipes

## Feature and compatibility requests

Use the **Feature request** template.

This project intentionally stays small and conservative. Requests should be narrow, reproducible fixes related to Create 0.5.1i on Minecraft 1.18.2 rather than new gameplay features.

When possible, link an upstream Create issue or another source showing the problem.

## Pull requests

Keep changes focused and explain what problem they solve. Avoid bundling unrelated cleanup with a compatibility fix.

Please test recipe changes in-game before submitting them.
